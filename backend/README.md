# KHOJAI Backend Architecture & Developer Manual

The KHOJAI backend is built with **FastAPI**, **SQLAlchemy 2.0 (Async)**, **Alembic**, and **Pydantic v2**, providing an asynchronous, secure, and modular foundation for destination intelligence and RAG pipelines.

---

## 📁 Directory Structure

```text
backend/
├── alembic/                    # Database schema migration scripts
│   ├── versions/               # Timestamped migration files
│   └── env.py                  # Alembic async migration environment
├── app/
│   ├── ai/                     # AI provider abstraction layer
│   │   ├── base.py             # BaseAIProvider interface
│   │   └── providers/          # Gemini, OpenAI, and Local implementations
│   ├── api/                    # API route definitions
│   │   ├── deps.py             # Authentication & database dependencies
│   │   └── v1/                 # Version 1 REST controllers (auth, chat, docs, search, users)
│   ├── config/                 # Pydantic Settings & environment validation
│   ├── database/               # SQLAlchemy engine, session maker, Base declarative
│   ├── models/                 # ORM entities (User, Conversation, ChatMessage, Document, etc.)
│   ├── rag/                    # Ingestion pipeline (cleaner, chunker, embeddings, extractor)
│   ├── schemas/                # Pydantic request/response validation schemas
│   ├── security/               # JWT token utilities, Bcrypt hashing, rate limiting
│   ├── services/               # Core business logic layer
│   └── main.py                 # FastAPI application factory & middleware stack
├── tests/                      # Automated test suite (81 tests)
├── init_db.py                  # Script to initialize SQLite/Postgres tables
├── requirements.txt            # Python dependencies
└── alembic.ini                 # Alembic configuration
```

## 🛠️ Prerequisites & Installation

```powershell
# 1. Create and activate virtual environment

# 2. Install dependencies
```

## ⚙️ Environment Configuration (`.env`)

Copy `.env.example` to `.env` in the project root:

```ini
APP_NAME=KHOJAI
APP_ENV=development
DEBUG=True
PORT=8000
HOST=127.0.0.1
API_V1_PREFIX=/api/v1

# Database: PostgreSQL (or sqlite+aiosqlite:///./khojai_dev.db for standalone local)
DATABASE_URL=sqlite+aiosqlite:///./khojai_dev.db

# Authentication (Minimum 32 characters for security)
JWT_SECRET=super_secret_development_jwt_secret_key_with_at_least_32_characters_12345
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
COOKIE_NAME=app_session_id
COOKIE_SECURE=False
COOKIE_SAME_SITE=lax

# AI Provider: 'local', 'gemini', or 'openai'
AI_PROVIDER=local
GEMINI_API_KEY=
OPENAI_API_KEY=
EMBEDDING_PROVIDER=local

# Storage & Uploads
MEDIA_DIR=./media
MAX_UPLOAD_SIZE_MB=20
```

## 🗄️ Database Migrations (Alembic)

Alembic manages schema evolution for PostgreSQL.

### Apply all pending migrations:
```powershell
alembic upgrade head
```

### Generate a new autogenerated migration:
```powershell
alembic revision --autogenerate -m "Add new column or table"
```

### Rollback the latest migration:
```powershell
alembic downgrade -1
```

### Initialize database tables directly (for local SQLite testing):
```powershell
python backend/init_db.py
```

## 🚀 Running the Server

### Development mode with live reload:
```powershell
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```

* API Documentation (Interactive Swagger): `http://127.0.0.1:8000/docs`
* OpenAPI Specification: `http://127.0.0.1:8000/openapi.json`
* System Health & Diagnostics: `http://127.0.0.1:8000/api/v1/health`

## 📡 REST API Endpoint Reference

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :---: |
| `GET` | `/api/v1/health` | Diagnostic health probe for database & AI | No |
| `POST` | `/api/v1/auth/register` | Register new user account | No |
| `POST` | `/api/v1/auth/login` | Login, issue JWT & session cookie | No |
| `POST` | `/api/v1/auth/refresh` | Refresh expired access token | Yes (Cookie) |
| `POST` | `/api/v1/auth/logout` | Revoke session and clear cookies | Yes |
| `GET` | `/api/v1/auth/me` | Current authenticated user summary | Yes |
| `GET` | `/api/v1/users/me` | Detailed user profile & travel preferences | Yes |
| `PATCH` | `/api/v1/users/me` | Update bio, avatar, and theme | Yes |
| `PATCH` | `/api/v1/users/me/preferences` | Update AI travel preferences | Yes |
| `DELETE` | `/api/v1/users/me` | Soft-delete user account | Yes |
| `POST` | `/api/v1/chat/conversations` | Create new chat thread | Optional |
| `GET` | `/api/v1/chat/conversations` | List user's conversations | Optional |
| `GET` | `/api/v1/chat/conversations/{id}` | Conversation detail & messages | Optional |
| `POST` | `/api/v1/chat/conversations/{id}/messages` | Send message & get AI response (SSE supported) | Optional |
| `DELETE` | `/api/v1/chat/conversations/{id}` | Delete conversation thread | Optional |
| `POST` | `/api/v1/documents` | Securely upload and process document | Optional |
| `GET` | `/api/v1/documents` | List uploaded documents | Optional |
| `GET` | `/api/v1/documents/{id}` | Document details and chunk previews | Optional |
| `POST` | `/api/v1/documents/query` | Ask questions from uploaded documents (RAG) | Optional |
| `DELETE` | `/api/v1/documents/{id}` | Delete document, chunks, and disk file | Optional |
| `GET` | `/api/v1/search` | Global omnisearch (destinations, docs, chats) | Optional |
| `GET` | `/api/v1/search/documents` | Hybrid vector & keyword search | Optional |
